🚀 QUICK START (Choose One Option)

Option A: Docker (Recommended - 2 minutes)
────────────────────────────────────────────
  1. cp .env.template .env
  2. docker-compose up -d
  3. curl http://localhost:8000/api/health
  ✅ Done!

Option B: Local Python (5 minutes)
────────────────────────────────────────────
  1. python -m venv venv
  2. source venv/bin/activate
  3. pip install -r requirements.txt
  4. cp .env.template .env
  5. mkdir -p data/{chroma,uploads,documents}
  6. python main.py
  ✅ Running on http://localhost:8000

Option C: Local Python + Ollama (Best Offline)
────────────────────────────────────────────────
  1. Install Ollama (https://ollama.ai)
  2. ollama pull mistral
  3. ollama serve (in another terminal)
  4. Follow Option B steps above
  ✅ Ready with local AI model!

🚨 TROUBLESHOOTING

Port 8000 in use?
  lsof -i :8000 | grep LISTEN | awk '{print $2}' | xargs kill -9

Ollama not connecting?
  ollama serve  (start in another terminal)

Missing dependencies?
  pip install -r requirements.txt

Database errors?
  rm -rf data/chroma data/aiko.db

WebSocket issues?
  Check CORS configuration in .env
  Verify backend is running

No LLM responses?
  Check LLM_PROVIDER setting
  Verify API keys if using cloud
  Check OLLAMA_BASE_URL if using local
